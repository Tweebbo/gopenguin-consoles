# GoPenguin for Nintendo Switch and Android

Native GoPenguin apps for Nintendo Switch and Android. They connect to the same island as
[gopenguin.lol](https://gopenguin.lol) and the [Nintendo 3DS app](https://github.com/Tweebbo/gopenguin-3ds),
so you play alongside everyone else.

This repository holds the release builds. The apps check its releases to update themselves.

## Install

**Android**

1. Open the APK link or scan its QR code on your phone or tablet.
2. When Android asks, allow your browser or file manager to install apps.
3. Open GoPenguin from your app list.

**Nintendo Switch**

1. Copy `gopenguin-0.2.1.nro` to the `switch` folder on your microSD card.
2. Open the Homebrew Menu and start GoPenguin.
3. Docked, use the controller. Handheld, you can also use the touch screen.

## Updates

GoPenguin checks for a new version when it starts and asks before installing it. Each download is
checked against its size and SHA-256 checksum first. You can also download any version from the
[releases page](https://github.com/Tweebbo/gopenguin-consoles/releases).

## What you can do

- Walk the island's rooms with the interface of the mobile app.
- Chat with an in-game keyboard.
- Play Pizzatron, Bean Counters and Ice Fishing for coins.
- Change clothes from the inventory on your penguin card.
- Become a member: scan a QR code on Nintendo Switch, or pay in your browser on Android.

The full list of changes is in [CHANGELOG.md](CHANGELOG.md) and on the
[GoPenguin changelog](https://gopenguin.lol/changelog/).
